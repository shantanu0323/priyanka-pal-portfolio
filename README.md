# Priyanka Pal Portfolio

Next.js (static export) + Less, deployed to GitHub Pages via `.github/workflows/nextjs.yml`.

## Develop

```bash
bun install
bun dev
```

## Deploy

1. Push this repo to GitHub.
2. In the repo: **Settings → Pages → Source: GitHub Actions**.
3. Every push to `main` builds and deploys. The base path is taken from the repo name automatically.
